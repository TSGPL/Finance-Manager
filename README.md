# UI-Finance-Tracker

A desktop finance tracker with a modern UI.

Features
- Add / Edit / Delete transactions
- Dashboard (Balance, Income, Expenses)
- Recent transactions view
- Multi-language support (DE / EN / RO / RU/ PL)
- Local JSON storage


Tech
- Python
- CustomTkinter
- JSON (local persistence)

Run
- Download Finance Tracker
- Unzip
- Run Finance Tracker.exe


Notes
- Data stored locally in JSON
- UI updates dynamically across pages
