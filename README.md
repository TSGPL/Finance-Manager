# UI-Finance-Tracker

A desktop finance tracker with a modern UI.

## Features
- Add / Edit / Delete transactions
- Dashboard (Balance, Income, Expenses)
- Recent transactions view
- Multi-language support (DE / EN / RO / RU/ PL)
- Local JSON storage


## Tech
- Python
- CustomTkinter
- JSON (local persistence)

## Run
- Download Finance Tracker
- Unzip
- Run Finance Tracker.exe


## Notes
- Data stored locally in JSON
- UI updates dynamically across pages

## Known Issues
- Edit Transactions tab isn't being Translated
- Window resizing can feel laggy on some systems.
- Changing the language may temporarily affect window layout (button sizes / width adjustments).
- Currency changes in settings do not update previously saved transactions or all dashboard values consistently.
- In some cases, edited transactions may not correctly update their type (income/expense) until refreshed.

## Planned Improvements
